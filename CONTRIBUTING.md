# Работа над проектом

Требуются Node.js 22+, FFmpeg/FFprobe. Установить зависимости разработки: `npm ci`. Для браузерных тестов: `npx playwright install chromium`.

1. Создать ветку для изменения.
2. Внести код и обновить документацию, если меняется поведение.
3. Выполнить `npm test`, запустить `npm start`, затем `npm run test:ui` в другом терминале.
4. Для изменений упаковки проверить `docker compose build` и `docker compose up -d --wait`.
5. Открыть pull request с описанием поведения и результатов проверок.

Не добавлять в Git пользовательские записи, транскрипты, токены, `.env`, временные файлы и архивы образов. Для тестов использовать синтетические записи. Не представлять демоданные как результат распознавания.
